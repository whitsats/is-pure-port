# I"s Pure 移植工程

记录如何把 PS2 版《I"s Pure》的场景、演出和流程转换到 WebGAL，并用安卓外壳离线运行。这个仓库提供过程、转换与验收脚本，以及相对上游引擎的源码补丁。

[查看图解项目页](https://whitsats.github.io/is-pure-port/) · [最新源码发布](https://github.com/whitsats/is-pure-port/releases/latest)

PS2 汉化是独立项目，原机补丁、翻译对照和打盘说明见 [is-pure-zh](https://github.com/whitsats/is-pure-zh)。

| 想了解什么 | 从哪里开始 |
| --- | --- |
| 原盘资源如何解析、转换和核对 | [移植过程](docs/移植过程.md) |
| 如何准备引擎、启动网页或构建安卓外壳 | [构建与本地素材](docs/构建与本地素材.md) |
| MAC 场景转换、分支与演出 | [转换器](移植验证/WebGAL移植/转换器/) |
| 如何验证脚本与网页运行结果 | [自动化测试](移植验证/WebGAL移植/tests/)、[浏览器验收脚本](移植验证/WebGAL移植/浏览器测试环境/) |
| 修改过哪些引擎和安卓源码 | [上游补丁](patches/) |

本仓库不提供原盘镜像、提取后的完整游戏资源、翻译底稿、漫画、存档或 APK。运行完整游戏需自行准备有权使用的素材。纯算法测试可以在没有这些素材的情况下运行。
