# 《I’s Pure》WebGAL 收尾验收计划

以 v7.4 打盘资料和 4204 正在提供的高清版为准。验收范围是从新游戏进入剧情、选择分支、存读档、各路线进入结局、片尾和返回标题。沿用当前 WebGAL 引擎及其存档、流程图和鉴赏功能。

四条角色线各开一个 Playwright 浏览器环境，在同一份 4204 构建上并行跑。任一路线卡住时保留它的证据，其余路线继续。Bad End 可以并行加入，或接到先跑完的环境中，用新的浏览器上下文初始化。

## 一、用新档建立基线

1. 在 [4204](http://127.0.0.1:4204/) 导入项目根目录的 `4204-开篇新档-2026-11-16.json`。在「选项 → 系统 → 导入存档与选项」选文件，再从「读档」打开第 1 槽。原生导入会替换当前浏览器的存档和选项，已有进度时先从同一菜单导出备份。
2. 从开篇推进到首次能改变数值的选项，记录选择前后七项数值及第一句对白。分别用普通存档和快速存档刷新恢复，各核对一次场景、句子、数值和继续后的首句。第 1 槽留作开篇基线，回归另用空槽。
3. 用下方三条命令复核两次蓝天转场、第 19 章留图和清图、状态页、代表性流程图跳转和两个结局样本。这批回归可与四条角色线并行。历史试玩档的句子编号迁移不在本轮范围内。

```powershell
node '浏览器测试环境/验证交接剩余任务.cjs' --transitions
node '浏览器测试环境/验证流程图与代表结局.cjs' --chart --status --endings
python -B -m pytest -q
```
