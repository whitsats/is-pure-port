# 《I’s Pure》与 WebGAL：为可玩移植做的功能对照

更新时间：2026-11-15。依据是本地原盘与脚本分析、用户已汉化素材，以及本项目 WebGAL 4.6.6 代码。表中“引擎支持”指 WebGAL 自身具备能力，不代表本作数据已经完成转换。

| 功能 | 已知的原作内容 | WebGAL 现有能力 | 本项目要做什么 |
|---|---|---|---|
| 开始、菜单、设置 | 已提取到原版菜单素材；PS2 界面与记忆卡机制是原实现 | 自带标题、系统设置和基本操作界面 | 直接使用 WebGAL，调整游戏名和必要配置，不复刻原菜单 |
| 剧情对白 | 原脚本、语音编号及 v7.4 汉化资料已提取 | 支持文字、逐句推进、语音 | 按剧本和偏移连接中文与语音，生成可连续执行的场景，补齐未对应条目 |
| 选择与分支 | 已识别 59 组选项、153 项的固定模式；部分选项依赖状态 | 支持选择、条件显示和跳转 | 保留原选项内容、原表索引及分支目的地，在运行时按状态显示并走向对应剧情 |
| 剧情变量、路线和结局 | 原程序有状态字/位及条件判断；具体哪些是好感度等未完全确认 | 支持普通变量、全局变量和条件跳转 | 转换会影响剧情的变化与判断；随存档恢复本周目状态，确有必要时保留跨周目状态 |
| 背景、人物、CG | 已解出 BG、CHR、EV；资源编号已有批量候选映射，显示层和具体位置仍需核验 | 支持背景、立绘、图层和基本变换 | 根据剧情指令选择素材与显示时机，处理必要的位置和叠层；允许使用默认或简化演出 |
| 语音、BGM、音效 | 已提取语音和音乐；部分声音编号和播放时机仍未建立可靠对应 | 支持对白语音、BGM 与效果音 | 批量建立资源编号到文件的对应，先接通主要语音和音乐，再补影响体验的音效 |
| 存档与读档 | 原版使用 PS2 记忆卡及内部状态复制 | 提供普通存档、快速存读档和自动保存；样片已测试读取、刷新恢复和变量传递 | 直接使用 WebGAL 存档。仅补回真正影响剧情的原版状态，不移植记忆卡格式或原存档界面 |
| 自动、快进、文本回看 | 属于游玩过程中的辅助操作；原版的具体操作与样式无需相同 | 当前引擎有自动、快进、回想及隐藏文字等控件 | 使用现有控件，验证在移植剧本里能工作 |
| CG／音乐鉴赏 | 原素材与菜单中有 CG、MOVIE 等相关资源；原版完整解锁规则尚未确认 | 本地版本的鉴赏界面包含 CG 与 BGM，可由脚本解锁 | 把已使用的 CG、音乐与鉴赏条目接入；不以复刻原版鉴赏布局为前提。当前未确认 WebGAL 现有视频鉴赏栏 |
| 影片 | 已有带声音的 OP、END 和 Logo 提取文件；OP 已做音画抽样对照，END 尚待试听 | 支持播放视频 | 最多接入开头 OP 与结尾 END 各一段；Logo 或额外视频不作为要求。实际播放与音画需测试 |
| 标题文字、消息窗、转场和特殊特效 | 原作有各类自定义表现，部分指令及参数已识别 | 有默认文字框、章节表现、动画与转场能力 | 采用现有样式或简化表现；以能理解剧情、画面合理为准，不把逐像素还原作为通关前置 |

## 哪些东西不能只靠引擎自动解决

WebGAL 不认识原作 MAC 字节码，也不知道某句对白对应哪条语音、某场戏应显示哪张图片，更不知道选项会修改哪些原游戏状态。要让游戏真正运行，仍需完成**剧本转换、资源对应、选择与状态逻辑、跨剧本衔接和验证**。可以复用 WebGAL 的舞台和功能，但必须把本作内容接进去。

不需要一模一样的部分，可以采用替代方案：例如原版 `quick_save` 的界面及记忆卡实现直接换成 WebGAL 存档；原版标题演出可简化为普通标题或跳过。但原指令中若存在影响后续选项、路线或结局的副作用，仍需保留其游戏效果。未知副作用先记录，优先通过可玩路径及状态数据判断，不以完整复刻底层为目标。

## 目前离目标的实际差距

- 现有电脑样片能测试一个真实三选项及其三条分支：分别为 124、107、95 句对白，并能切入下一剧本的验证场景。**还不是从开头到结局的完整游戏**；样片的部分初始状态是假设值，背景仍手工指定。
- 已将部分状态写入 WebGAL，并验证样片的快速存读档、刷新恢复及跨场景传递；**完整剧情的运行时变量和全部选择尚未接通**。
- 在已有核查的 22 个剧本的 9,800 条对白中，已有 9,753 条建立 v7.4 工程关联；静态清单的 153 条选项中已有 64 条通过地址与原文严格关联。剩余数字代表**当前对照工具尚未匹配**，不代表原游戏没有汉化，需要继续从已有汉化资料及游戏资源中补齐；这些数字也不是全游戏覆盖率。
- 已提取的素材不等于已经自动在正确时机显示或播放。目前 `graph_disp`、部分 SE、淡入淡出等仍多为记录而未映射，必须先接通真实背景、人物和音乐，才能成为正常游玩的游戏。
- 开头接续目前在原版状态处理、简化存档之后，遇到章节标题显示指令停止。原版存档内部格式无需完整移植；下一步采用 WebGAL 的等效能力或简化章节显示，继续验证后续正文和画面。

## 完成判据

玩家能在移植版从开始进入游戏，阅读已汉化剧情、听到对应语音和主要音乐、看到剧情所需画面、选择不同选项并抵达相应结局；保存、退出和恢复后剧情位置及相关变量正确。开头和结尾视频至多各接一段。电脑端先验证，安卓端再验证触摸、声音、离线运行及存档。
