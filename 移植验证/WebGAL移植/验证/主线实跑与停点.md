# 主线连续实跑与停点（2026-11-15）

从新游戏出发，一路真实点击（选项按第 1 项选取）到 `MAC_056` 的结束指令，逐章记录运行时标题、
首句对白、请求到的语音编号，并读回状态变量。样片 `新游戏打盘版/public`，端口 4203。

## 一条命令复现

```bash
cd 浏览器测试环境
node 跑主线到终点.cjs --pick 0 --report ../数据/主线实跑_全流程.json
```

单次约 14 分钟（32,350 次点击、8,072 个不同语音请求，实测 846 秒）。报告 `数据/主线实跑_全流程.json`，
逐章字段：`title`、`title_seen_in_runtime`、`intro_snapshot`、`entry_scene`、`first_text`、
`state_readback`、`voices`。

## 变量读回为什么以前是空的

Vite 开发服务器给模块加了 HMR 查询串，页面实际加载的是

```
/src/Core/Modules/stage/stageStateManager.ts?t=1794730839972
```

脚本里若直接 `import('/src/Core/Modules/stage/stageStateManager.ts')`，拿到的是另建的模块实例，
`GameVar` 永远是空对象。现在脚本从 `performance.getEntriesByType('resource')` 里取出页面真实加载的
URL 再 import，读到的是同一份 `stageStateManager`：

- 进入任意章节时都能读回 `mac_6007`、`mac_6000`、`mac_entry` 等真实操作数（`vars_count` 记录当时
  已创建的变量个数，早期章节只有 8 个，后期到 20 多个）；
- `MAC_009` 选「走廊」（第 0 项）后，`MAC_010` 入口读回 `mac_6007 = 0`、`mac_6000 = 0`，
  与选项序号一致（`state_checks[0].pass = true`，见报告 `state_checks`）。

## 选项为什么能真实选中

引擎的选项容器用 emotion 生成的类名（`css-1vw1yyx` / `css-1a0qwn0`），不含 `Choose_item`；
脚本改为取 `#chooseContainer` 里的叶子 `div` 并按其包围盒点击。正文推进点击左下角 (100, 650)，
不会误点屏幕中央的选项。一次完整实跑共记录 42 个选项，含 `MAC_009` 五项的全套文本。

## 实跑结果

- 53 章全部到达（`MAC_004` 起算；`MAC_001`–`MAC_003` 在更早的脚本里）。
- 最远：`MAC_056「Ｉ´ｓ」`，末章首句 `？？？「啊―，要迟到了要迟到了，要迟到啦―！」`。
- 结束指令：`MAC_056.bin 0x2D88`，原始字节 `01010000`（`end`），场景 `mac_056_0x002d48.txt`，
  边界行「本版边界：MAC_056.bin 0x2D88 end（end）。」
- 语音：8,072 个不同 `VOICE_*.wav` 请求成功；逐章编号见报告 `chapters[].voices`。
- 章节标题卡在 47/53 章被运行时捕获（`title_seen_in_runtime`）；其余 6 章的标题由场景 `intro:` 指令
  静态核对（测试 `test_chapter_scenes_open_with_the_static_title`）。MAC_056 只有 6 行（`first_text_source:
  scene_file`），其余 52 章的首句都是运行时抓到的。
- 全程无 `stalled`；`pageerror` 为空（控制台仅有 2 条静态资源 404 与 WebGAL 同步 WebSocket 超时，
  与剧情推进无关）。

