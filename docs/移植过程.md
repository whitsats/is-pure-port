# 从 PS2 原盘到 WebGAL

移植的关键是保留原作的分支条件、出场顺序和语音时点。素材解包与指令解释先独立验证，再把可确认的行为写进 WebGAL 场景。

| 阶段 | 入口 | 怎样核对 |
| --- | --- | --- |
| 盘面和容器 | [扫描 ISO](../移植验证/扫描_ISO文件.py)、[扫描 AFS](../移植验证/扫描_AFS容器.py) | 记录文件大小、偏移和容器条目。 |
| 背景、立绘和 CG | [保护边修复提取](../移植验证/输出保护边修复素材.py) | 对照原画构图、透明度和保护边，保留源尺寸清单。 |
| 声音与影片 | [提取 BGM](../移植验证/提取BGM音乐.py)、[输出影片](../移植验证/输出视频素材.py) | 分别核对语音、音乐和音效。安卓片头保留 2400×1080 的 faststart 文件。 |
| 剧本与译文 | [MAC 解析](../移植验证/MAC_解析.py)、[地址对齐](../移植验证/WebGAL移植/转换器/对齐v74地址.py) | 按指令偏移和日文原句对齐，保留候选和不确定项。 |
| 流程与演出 | [批量接入章节](../移植验证/WebGAL移植/转换器/批量接入章节.py)、[生成流程图](../移植验证/WebGAL移植/转换器/生成流程图.py) | 检查选项、跨场景跳转、状态写入、图鉴和声画时点。 |
| 漫画与安卓 | [PDF 转 WebP](../移植验证/WebGAL移植/工具/漫画处理工具/convert_pipeline.py)、[离线资源打包](../移植验证/WebGAL移植/工具/安卓打包/打包高清资源包_ZIP.py) | 按卷检查页数与顺序；验证冷启动、后台暂停和横竖屏。 |

从仓库根目录执行下面的命令，可以先检查本机是否能运行提取和编译入口。只提取一小批背景，便于核对输出。

```powershell
$env:IS_PURE_ORIGINAL_ISO = 'X:/own-disc/game-original.iso'
python -m pip install Pillow pytest
python '移植验证/输出保护边修复素材.py' --only BG --range 0 4 --out '素材/抽样'
python '移植验证/WebGAL移植/转换器/批量接入章节.py' --help
```

生成完整场景还需要本地素材、指令证据和译文对照表。批量脚本的 `--report` 记录阻塞项。遇到未确认指令，先回查源位置与原盘运行结果，再补转换规则。生成后的场景、原始报告和漫画页只留本地。

更多底层记录见 [MAC 剧本格式](../移植验证/MAC剧本格式说明.md)、[命令表与分支验证](../移植验证/MAC_原程序命令表与分支验证.md)、[跨剧本入口](../移植验证/MAC_跨剧本跳转与入口.md)。
