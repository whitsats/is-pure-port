# 批量章节接入（从 MAC_007:0x4314 起）

## 一条命令跑完整条主线

```powershell
# 在 移植验证/WebGAL移植
python -B 转换器/批量接入章节.py --from MAC_007:0x4314 `
    --report 数据/批量章节扫描_写入2.json `
    --manifests 语音校验_MAC007_语音1391至1723.json 语音校验_MAC008至MAC009_语音新增.json `
                语音校验_MAC010开篇_语音1851至1915.json 语音校验_批量章节_语音1214至12789.json `
    --write 新游戏打盘版/public
```

脚本沿 `数据/全盘剧情候选图.json` 自动发现章节入口，按 `数据/全盘主线接线_打盘版.json`
接续跨章 `ext_goto`，对每章调用 `compile_chapter`，并在同一次运行里核对：

- `changeScene` 目标场景是否存在；
- 场景引用的 `VOICE_*.wav` 是否存在；
- 该章实际用到的状态字是否都能初始化（`check_layout` 拒绝字/位共用地址）。

`--verify-voices` 可以先用 `转换器/校验语音样本.py` 一次性核完缺失编号再编译；
本轮把 10,230 个编号合成 `数据/语音校验_批量章节_语音1214至12789.json`（ADX 与原盘
逐字节相同、WAV 与重解码 PCM 一致），因此现在直接列清单即可。

## 按类型处理的停点

| 类别 | 处理 | 依据 |
| --- | --- | --- |
| 跨章 `ext_goto` | 写成 `changeScene`，目标场景同批生成 | 接线表的 `emitted` |
| 章节内选项 | 生成 `choose:` + 原序号写回 | `mac_story_wiring.emit_choice`，33 组已核 |
| 类型 1 粒子特效 | 保留启动/结束请求/完成检查，画面省略 | `数据/effect_start_wait_隔离执行.json` |
| 类型 3 换屏特效 | 完成等待近似 134 ms，画面省略 | `数据/MAC006演出指令隔离执行_八帧.json` |
| 类型 6（MAC_020） | 同一完成协议，17 ms 近似 | 原字节登记于 `转换器/mac_effect.py` 的 `EXTRA_STARTS` |
| 类型 12（MAC_013/028/032/049/054/055） | 同上，按参数 4/6/8/9/12/0x0F 分别登记 | 同上；结束请求与完成检查走 `6b02fc`/`6b02fd` |
| `save_lock` | 只记账，不生成语句（原处理器推进 4 字节） | `数据/跳转与等待ELF证据.json` 同族 |
| `movie_play` | 跳过影片，记 `movie_omitted` | 原字节 `52010100`，样片不渲染视频 |
| `end`（`01010000`） | 作为场景终点，写边界行 + `end;` | 7 条支线都汇到 `MAC_056:0x2D88` |
| 纯控制码对白（`%p/%P/%K/%O`） | 去掉控制码；为空则只推进 | `数据/台词及控制码核查.tsv` 的分类 |
| v7.4 未译行（264 条） | 按原日文显示，记 `untranslated_japanese` | `数据/未译对白清单.tsv` |

未译行不是编译阻塞，也不再让整章停下；清单里保留剧本、指令偏移、文本偏移、
日文原文、语音号与原字节，便于后续统一补译。

## 七个结局

7 条支线都在 `MAC_056:0x2D88` 收束（原字节 `01010000`），因此 WebGAL 侧是
7 个不同场景汇到同一个终点。终点目前只写边界行和 `end;`，原版的结局演出与
回标题没有还原；这是"离线到达结束指令"的性质，实机连续游玩仍需人工确认。
