# 构建与本地素材

两个上游工程作为本地依赖保留各自的 Git 元数据与许可证。本仓库公开相对固定上游版本的补丁，内容可在 GitHub 上直接阅读。

| 组件 | 上游版本 | 公开补丁 |
| --- | --- | --- |
| WebGAL | [15173bc](https://github.com/OpenWebGAL/WebGAL/commit/15173bc) | [WebGAL.patch](../patches/WebGAL.patch) |
| 安卓外壳 | [07fb190](https://github.com/OpenWebGAL/WebGAL-Android/commit/07fb190) | [WebGAL-Android.patch](../patches/WebGAL-Android.patch) |

全新检出时，在仓库根目录执行：

```powershell
$web = '移植验证/WebGAL移植'
git clone https://github.com/OpenWebGAL/WebGAL.git "$web/engine"
git -C "$web/engine" checkout --detach 15173bc
git -C "$web/engine" apply (Resolve-Path 'patches/WebGAL.patch')

git clone https://github.com/OpenWebGAL/WebGAL-Android.git android-is-pure-prototype
git -C android-is-pure-prototype checkout --detach 07fb190
git -C android-is-pure-prototype apply (Resolve-Path 'patches/WebGAL-Android.patch')
```

## 素材位置

- 原盘镜像可放到 `素材/PS2原盘/game-original.iso`，或通过 `IS_PURE_ORIGINAL_ISO` 指定。
- 转换器默认查找同级 `is-pure-zh` 的本地汉化资料。可用 `IS_PURE_ZH_ROOT` 或 `IS_PURE_V74_RELEASE` 指向其他位置。
- 高清 WebGAL 运行目录是 `移植验证/WebGAL移植/新游戏打盘高清版/public/game`。后续命令假定已经按 [移植过程](移植过程.md) 生成场景，并准备好背景、立绘、声音、配置及模板。
- 漫画可选，指定自己有权使用的完整册 PDF 目录。转换得到的页图放到 `game/manga`。

```powershell
python -m pip install PyMuPDF Pillow
python "$web/工具/漫画处理工具/convert_pipeline.py" --input 'X:/owned-manga/超清完全版全12卷' --output "$web/新游戏打盘高清版/public/game/manga"
```

## 网页和安卓构建

WebGAL 使用 Node.js 和 Yarn 1。进入 `移植验证/WebGAL移植/engine` 执行 `yarn install` 和 `yarn parser:build`，然后运行本项目的 [高清启动脚本](../移植验证/WebGAL移植/运行新游戏打盘高清版.cmd)。

安卓需要 JDK 和 Android SDK。进入 `engine/packages/webgal` 运行 `yarn vite build --config is-android-shell.vite.config.ts`。本地准备 `android-is-pure-prototype/app/src/main/assets/webgal/MV_OP01_phone60.mp4` 和 `app/src/main/res/drawable-nodpi/is_pure_mark.png`，它们分别是从原片制作的完整片头与本地应用图标。随后在安卓工程执行 `gradlew.bat :app:assembleDebug`。自己准备的高清 `game` 目录可以用 [资源打包脚本](../移植验证/WebGAL移植/工具/安卓打包/打包高清资源包_ZIP.py) 生成离线 ZIP。

在仓库根目录可以运行不读取原盘或完整场景的测试：

```powershell
python -m pytest '移植验证/test_MAC_条件求值.py' '移植验证/WebGAL移植/tests/test_fade.py::FadeParserTests'
```

完整验收还依赖本地镜像、构建结果和测试证据。浏览器验收脚本使用 Playwright。
