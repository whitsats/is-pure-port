# 第三组选项的运行时状态

本轮没有启动 PCSX2。原版指令验证使用之前运行隔离 PCSX2 留下的空白卡即时存档。当前 WebGAL 流程、分支和存档验证使用命令行启动的无头 Edge。证据范围和下一步见 [最新交接](../当前进度_2026-11-15_后续接手.md#最新交接动态剧情与批量转换)。

开局 `MAC_000:0x1C` 写入 `0x602C=20`。首组选「少扯了！」执行 `MAC_001:0x4044` 的加一，第二组选「走廊」执行 `MAC_002:0x70C` 的减一。WebGAL 在原剧本对应位置执行这些赋值和加减，跨场景沿用舞台变量。

`MAC_003:0x24A4` 先写 `0x6010=1`。若 `0x602C<21`，`0x24AC` 跳到选项，否则经过 `0x24BC` 清零。WebGAL 直接执行这三条状态和跳转操作，「青梅竹马而已」按当前 `0x6010` 显示。实际对白场景仍按已有路径展开，其他剧情变量和条件尚待迁移。

原版证据来自空白卡隔离存档的内存副本，向原处理器输入 19、20、21。前两个值分别生成原选项序号 `[0,1,2]`，21 生成 `[1,2]`，选中第一行时写回原序号 1。程序调用原计算、比较及选项函数，界面绘制和点击用测试桩提供。详情见 `数据/第三组选项原版状态核查.json`。

无头浏览器从标题进入新游戏，实际点击三条路径。道歉 → 走廊得到 19，少扯了！ → 走廊得到 20，少扯了！ → ２年教室得到 21。显示条件与原处理器一致。三条路径均核对了分支首句，并在选定后快速存档、推进、读档和刷新继续，恢复的舞台变量及原选项编号一致。回归套件 184 项通过。

`数据/剧情状态直接引用.json` 记录 73 个候选剧本里可解码的条件、运算和已解析选项引用。发现 107 个操作数、17 处待查项，已解码引用未出现字和位共用同一地址。扫描范围外的间接读写、原生代码和未解析剧本仍需核查。运行时输出层遇到跟踪字与其他操作数共用地址时会显式拒绝，通用共享字节模型待完成。

从第三组 `MAC_003:0x24C4` 到第四组 `0x34AC`，新增一个共享场景。进入时玩家选中的原序号写入 `0x6007`，共用场景执行原偏移对应的条件跳转、加减、字赋值和已用到的位赋值。它沿用前序剧情实际维护的舞台变量。第四组选项可见、可选，写回原序号后结束当前验证版。第三组选项以前的对白场景仍按已有路径展开，这一段的画面、音效和转场沿用此前的简化范围。
